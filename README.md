# WAHA

Браузерная тактическая RTS: капитан-герой с кастомизацией, строители и постройки, отряды с пополнением, захват точек, лобби и матчи по сети.

## Запуск

```
npm install
npm run dev          # http://localhost:5173 (PORT=5180 npm run dev, если порт занят)
npm test             # тесты симуляции
npm run check        # типы
npm run build        # production-сборка клиента в dist/
npm start            # production-сервер после сборки
```

Один процесс: Vite отдаёт клиент, тот же сервер держит WebSocket `/ws` (лобби и матчи).

## Как играть

Создайте лобби, добавьте бота (или отправьте ссылку-приглашение другу), нажмите «Готов» и «Начать матч».

- Старт: штаб, капитан, строители. Строители ставят **казармы** (B) и **посты** (P) на захваченных точках.
- Штаб нанимает строителей, казармы нанимают **отряды гвардии** (5 бойцов). Потери пополняет **R** за requisition.
- Точку захватывают стоя в ней. Пост на своей точке даёт больше requisition и держит её.
- Победа: снести штабы врага и все здания, где появляются войска (казармы, техцех, верфь, врата).
- Управление: ЛКМ выбор или рамка, ПКМ приказ, Q+ЛКМ атака-движение, Z стоп, Пробел капитан, H штаб, WASD/стрелки/край экрана камера, колесо зум, **Shift+M** звук.

## Решения

- **Сеть:** сервер считает всю симуляцию (20 Гц), клиентам шлёт снимки 10 Гц, клиент сглаживает. Нет чита maphack-ом, простой reconnect-в-бота. Минус: трафик и CPU сервера. Лимит: JSON-снимки без дельт (`ponytail:` в server/index.ts).
- **Правила только в `shared/sim.ts`:** чистые функции, без DOM и сети. Клиент рисует, сервер считает, бот играет теми же командами.
- **Графика:** живые модели Three.js в `client/world3d.ts`; модели и анимации юнитов, техники и зданий — в `client/models3d/`. Превью капитана использует `client/snap3d.ts`. Поле боя рисуется напрямую в 3D, без запекания в пиксельные атласы. Стили интерфейса — в `client/index.html`.
- **Звук:** синтез Web Audio (`client/audio.ts`), файлов нет.

## Фракции и просмотр моделей

Шесть игровых фракций заданы в `shared/factions.ts`: Космодесант (`order` → `legion`), Некроны (`clockwork` → `necrons`), Орки (`orks` → `scrap`), Хаос (`ashen` → `heretics`), Тёмные Эльдар (`eldar` → `drukhari`), Тираниды (`tyranids`). Отдельные демоны богов Хаоса относятся к ростеру Хаоса.

Откройте `/units.html`: карточки показывают актуальные 3D-модели из игры; клик открывает живую модель с выбором её анимаций. Справочник включён и в production-сборку. Существующие WebP-ассеты в `client/public/models/factions/` сохранены для иконок и резервного отображения; они не заменяют живые модели на поле боя.
