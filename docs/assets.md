# Фракционные ассеты: первый рабочий проход

Пакет подготовлен на ранней версии WAHA с Three.js. Последующие изменения `main`, включая переход игры на 2D, в эту экспериментальную ветку не перенесены.

Для просмотра без установки скачайте `client/public/art/faction-lab-standalone.html` и откройте файл в браузере. Модели, текстура земли и код уже включены в HTML. Документ проверен с отключёнными сетевыми запросами: сцена, кратеры и экспорт GLB работают.

Выбранные фракции: космодесант, Хаос, орки и некроны. Оригинальные названия армий и эмблемы заданы в пресетах. Визуальное направление — детальный готический sci-fi, читаемые силуэты и пиксельное представление с камеры сверху под углом.

## Рекомендуемый подход

Для текущего Three.js и планов на стрельбу, кратеры и разрушения подходит 2.5D: ортографическая камера, объёмная земля и модели, низкое разрешение с целочисленным масштабированием, спрайтовые эффекты. При фиксированной камере персонажей можно заранее запечь в спрайты, сохранив объёмное окружение.

Рисованная 2D-пехота даёт больше контроля над каждым пикселем, но требует согласованных кадров каждого действия в каждом направлении. В этой заготовке 12 персонажей × 5 действий × 8 направлений × 8 кадров = 3840 кадров. Генерация иллюстраций сама по себе не обеспечивает стабильность такой анимации. Запекание одной модели сохраняет пропорции и экипировку во всех кадрах.

Низкое разрешение помогает получить пиксельный вид; финальное качество зависит также от формы, текстур, света и эффектов. Близость к референсу следует оценивать в игровом масштабе. Пакет ниже — процедурный прототип формы и движения. Он ещё не достиг детализации художественного референса.

## Что создано

- `client/public/art/factions-reference.png`: целевой художественный образ четырёх фракций. Нижняя полоса иллюстрирует движение, но не является игровым атласом.
- `client/faction-models.ts`: 12 персонажей из подвижных жёстких частей; четыре роли построек у каждой фракции.
- `client/public/models/factions/<фракция>/<роль>/model.glb`: 28 экспортированных моделей. Каждый из 12 персонажей содержит пять именованных клипов; всего 60 клипов. Это иерархическая анимация отдельных деталей, без скиннинга и симуляции ткани.
- `.../<роль>/sprites/<анимация>.png` и `.json`: 60 прозрачных атласов 1024×1024; в каждом восемь строк направлений и восемь столбцов кадров. Метаданные задают длительность, цикличность, углы, координаты кадров и опорную точку на земле. Масштаб общий для всех персонажей.
- `tools/faction-presets.mjs`: художественные пресеты для 28 ассетов, палитры, требования к материалам, бюджетам и анимациям.
- `client/asset-lab.html`: интерактивный полигон. Фракции, анимации, сравнение пиксельного и чёткого представления, залп, кратеры, разрушение штаба и экспорт.

Капитан: `idle`, `walk`, `run`, `attack`, `death`. Пехотинец: `idle`, `walk`, `run`, `shoot`, `death`. Строитель: `idle`, `walk`, `run`, `work`, `death`.

Запуск из корня репозитория: `npm run dev`. Полигон доступен по пути `/asset-lab.html` на этом сервере. `npm test` проверяет симуляцию; `npm run check` проверяет TypeScript.

На полигоне деформируется геометрия земли и остаются следы выгорания. Частицы взрыва временные, у разрушенного штаба остаются обломки. Эти эффекты пока не подключены к сетевой симуляции игры, её столкновениям или поиску пути. Это проверка способа представления, а не завершённая система разрушения мира. В основной игре ещё нет выбора этих четырёх фракций.

## Повторная генерация

При работающем dev-сервере выполните `node tools/bake-factions.mjs`. Скрипт экспортирует текущие процедурные модели и запекает анимации без внешнего API. Обновляются только сгенерированные ассеты в `client/public/models/factions/`.

В этой облачной среде Chromium и Playwright Core уже доступны. На другой машине установите Chromium и Playwright Core отдельно от зависимостей игры. Например:

```sh
npm install --prefix /workspace/scratch/waha-art-tools --cache /workspace/.npm-cache --no-audit --no-fund playwright-core@1.56.0
WAHA_PLAYWRIGHT_MODULE=/workspace/scratch/waha-art-tools/node_modules/playwright-core node tools/bake-factions.mjs
```

`WAHA_CHROMIUM_PATH` задаёт путь к Chromium, `WAHA_DEV_URL` — адрес уже запущенного dev-сервера. По умолчанию используются `/usr/bin/chromium` и порт 5173. Не запускайте несколько Vite-серверов одновременно: HMR использует порт 24678.

## Необязательный Meshy

Существующий генератор расширен фракционными пресетами. `node tools/meshy.mjs --faction necrons --dry-run guard` выводит полный план без ключа, сетевых запросов и оплаты. Аналогично доступны `legion`, `heretics`, `scrap`; без списка ролей выбираются все семь ассетов фракции.

Запуск без `--dry-run` создаёт платные задачи через Meshy и требует `MESHY_API_KEY`. Ключа в среде нет; Meshy-генерация и соответствие её API не проверены. Процедурный пакет выше создан без Meshy. Для сторонней генерации сначала проверьте одного персонажа, его материалы, риг, клипы и соответствие художественному референсу, затем расширяйте пакет. Автоматический выбор первой подходящей библиотечной анимации требует визуальной проверки.

Общий путь вывода Meshy совпадает с процедурным пакетом. Экспортируйте или сохраните текущий пакет перед заменой моделей сторонней генерацией. Основной загрузчик игры сейчас читает другой каталог (`models/meshy`); подключение фракций требует отдельной интеграции.

## Следующие этапы качества

Детальные формы и материалы по художественному листу, оружие и корректные хват/отдача, техника и тяжёлые юниты, спецэффекты по фракциям, локальные повреждения построек. Для массовых армий нужны профилирование и сокращение количества отрисовок; производительность этого полигона не доказывает готовность к сотням юнитов. Полноценная деформация земли потребует согласования с сервером, навигацией и размещением построек.

Текстура земли взята из существующих ассетов репозитория; лицензия находится в `client/public/tex/LICENSE.txt`.
