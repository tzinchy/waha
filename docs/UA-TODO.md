Общий список для сессий Claude. Берёшь задачу — сразу ставь `[в работе: <имя сессии>]` и сохраняй файл, закончил — `[x]` и одна строка, что сделано.

Статусы: `[ ]` свободна · `[в работе: имя]` · `[x]` готово.

## Жалобы после игры (27.10)

- [x] 21. Скорость UA ×0.5 вместо ×DOW_M (Серые рыцари 24 → 8 м/с), дальность и обзор — по-прежнему ×DOW_M.
- [x] 22. Здания бьют одним лучшим стволом (бункер — не 4 пулемёта сразу); пост Инквизиции без аддона-ствола молчит (`UA_UNARMED`).
- [x] 23. Пост — только на своей точке; мины, бункер, стены, ворота — не на чужой и ничьей точке (сервер и превью).
- [x] 24. «Поддержка» и «снайпер» у рас UA — обычные боевые отряды: без ауры знаменосца, подпись «Пехота · стрелки/ближний бой».
- [x] 25. (28.10, waha-3e) «Улучшение одной Инквизиции появляется у другого игрока». Сим и снимки чисты (проверено дважды), причина — клиент: панель приказов строилась и для выбранного чужого здания — его очередь, прогресс исследования и аддоны (`st.q`, `ad` здания) показывались кнопками своей расы; у двух Инквизиций списки совпадают, и чужое улучшение выглядело своим («готово» / «идёт»). Теперь у чужого выбора панели приказов нет (`buildCells`). Если повторится на своём здании — нужен сценарий.
- [x] 26. Модели при постройке летали по карте: у Инквизиции стройка — цепочка клипов build1…N, мы тянули один `build1_landing` (капсула на 90–130 м над землёй) на всю стройку. Теперь цепочка по доле готовности без посадки/взлёта (`UAActor.buildSeq`).
- [x] 27. (`UAActor.aim`: кость из клипа `aim_horiz` мода по `face` здания; выстрел/удар — клип с начала на каждый выстрел (`shotAt`), без зацикливания) Анимация стрельбы: турели к цели, темп = перезарядка. Эффекты — задача 19.
- [x] 28. (28.10, waha-3e) Баланс: бои без браузера (scratchpad bal.mts: роль тиранид × роль Инквизиции, равная цена влияние + 2×энергия, «Перевал»). Найден баг: стрелковым ролям давался первый стрелковый ствол точки — т.е. покупной: воины тиранид бесплатно с пожирателем и биоплазмой (228 урона/с на бойца, выигрывали у всего, включая Лэнд Рейдер), карнифекс — с душителем и биоплазмой, равенеры, иерофант, уберфекс тоже. Теперь ствол по умолчанию — первый в точке, как в DoW (`modDefault`), пустышка — точка пуста до покупки; купленный стрелковый ствол даёт бойцу дальность (`armRange`, `u.st`); у зданий по-прежнему ствол от аддона. После: средний перевес тиранид +6.8% (было +11.2), 44 побед из 81 против 37. Остаток — цифры мода и чего нет в игре: способности (Астропат-«снайпер» Инквизиции — разведчик со способностями, в бою проигрывает всем), энергия тиранидов в ценах мода почти 0. Клиент считает дальность бойца так же (`armedStat` по снимку `wu`) — карточка и выбор целей показывают купленную дальность.
- [x] 30. Победные очки удалены (сим, снимок, полоска и счёт в HUD): перевес по точкам ни на что не влиял. Ромбы точек остались.
