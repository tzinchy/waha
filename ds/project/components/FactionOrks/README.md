# FactionOrks

Пресет фракции «Ржавая Орда»: тема интерфейса `orks`, палитра мира, базовый состав по тирам и особая механика.

**Как применить**
- Интерфейс: `data-theme="orks"` на корне HUD (или на любом контейнере) — все `lc-*` компоненты перекрашиваются: металл рамок, поверхности, кольцо фокуса. Сигнальные цвета (`verdigris-*`, `blood-*`, `amber-*`) одинаковы у всех фракций — игрок не переучивается.
- Мир: класс `fac-orks` на силуэте (`svg.lc-art`) — те же цветовые зоны берут палитру фракции (`orks-main` … `orks-cloth`).

**Особая механика.** **Ярость.** Шкала растёт от рукопашной и убийств. Когда она полна, Вожак бьёт в барабан: вся орда +30% скорости и урона на 20 с. Лимит Легиона даёт число Тотемов, а не казармы.

**Модификаторы:** пехота дешевле на 20% влияния; ярость; броня −15%.

**Состав (база):** Мастеровой — строитель, тир I, Рубака — пехота, тир I, Вожак — элита, тир II, Идол-Таран — титан, тир IV, Становище — штаб, тир I.

**Язык форм**
- Приземистые, сутулые, асимметричные; клыки, рога на шлемах, заклёпки, листы лома. Ржавчина и кожа оливкового цвета, боевая краска полосами. Техника — на гусеницах и колёсах, с дымом.
