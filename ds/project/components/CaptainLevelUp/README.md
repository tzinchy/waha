# CaptainLevelUp

Прокачка капитана в бою: шкала опыта на HUD, источники опыта и выбор дара при новом уровне.

**Части**
- `lc-caphud` — портрет, ромб уровня `lc-capbadge`, шкала `lc-xp` (заполнение `--xp`), строка «ур. 6 → 7 · 340 / 500».
- `lc-levelup` — окно нового уровня: вращающееся ар-деко солнце `lc-burst`, «Ранг N», две карточки `lc-choice` с клавишами 1 / 2.

**Опыт** (пример): убийство пехоты +5, элиты +40, техники +60, титана +200; захват точки +25; победа отряда рядом с капитаном +10. Уровни 1–10; к уровню нужно 100 × уровень опыта.

**Правила**
- На каждом уровне — выбор из двух даров: улучшение изученной способности или новая из открытого тира. Не выбрал за 15 с — окно сворачивается в ромб над порталом капитана, выбор не теряется.
- Игра не ставится на паузу; окно открывается в правой части экрана и не перекрывает сетку команд.
- Новый уровень — короткая вспышка-кольцо `gilt-300` вокруг капитана в мире и звук колокола. Гибель капитана не сбрасывает уровень: он возрождается у штаба через 30 с × ранг.
