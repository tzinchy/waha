# Button

Кнопка с срезанными углами и двойным контуром — основное действие игрока в меню и окнах.

**Разметка:** `<button class="lc-btn">ГЛАГОЛ</button>`; иконка — inline `<svg>` первым ребёнком (берёт `currentColor`).

**Варианты**
- `lc-btn` — латунная заливка `gilt-500`, текст `on-gilt`, фаска `shadow-bevel`. Одна на экран/окно: главное действие.
- `lc-btn--ghost` — контур `gilt-500`, фон `surface-200`, текст `gilt-300`. Второстепенные действия.
- `lc-btn--blood` — `blood-600` с текстом `on-blood`. Только необратимое: снести здание, сдаться, распустить отряд.
- `lc-btn--sm` — 32px, фаска `chamfer-sm`. Внутри панелей и подсказок.
- `disabled` или `aria-disabled="true"` — серый контур `hairline`, текст `ink-disabled`. Причину покажите в подсказке.

**Правила**
- Текст — глагол прописными (`label-lg`): «ВОЗВЕСТИ», а не «ОК».
- Высота 44px — минимальная цель для мыши и геймпада.
- Фокус — сплошное кольцо `focus-ring` вокруг всей кнопки.
- Не ставьте две латунные кнопки рядом: вторую делайте `--ghost`.
