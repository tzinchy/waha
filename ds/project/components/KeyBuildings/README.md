# KeyBuildings

Ключевые здания тиров и их исследования: список зданий слева, панель выбранного здания с очередью исследований справа.

**Части**
- `lc-keycard` — здание в списке: силуэт, имя, статус («построен · 2/4», «исследует», «нужен тир III»), метка тира. Выбранное — `aria-pressed="true"`, не построенное — `lc-keycard--none`.
- `lc-keyhead` — живой силуэт выбранного здания (`lc-anim-work`), имя и роль.
- `lc-rcard` — исследование: ромб-иконка, имя, эффект (бонусы `verdigris-300`), цена с `lc-ico`, состояние:
  `--done` «Изучено» · `--active` «Идёт · 64%» с полосой прогресса `gilt-300` · `--open` «В очередь» · `--locked` с требованием `blood-300`.

**Исследования Ордена**

| Здание (тир) | Исследования |
| --- | --- |
| Скрипторий (I) | Литании стойкости — пехота +2 брони · Ускоренная присяга — найм пехоты −15% времени · Знамёна рот — мораль +20% · Свитки каменщиков — стройка +20% |
| Храм-кузня (II) | Закалённая латунь — техника +3 брони · Орган-пушки II — урон бронехода +25% · Глубинное бурение — насосы +25% · Шаги шпиля — шагоходы +10% скорости |
| Обсерватория Лампы (III) | Дальний свет — обзор маяков +8 м · Небесное наведение — артиллерия +20% точности · Знамение — титан и легенды врага видны на мини-карте · Звёздная карта — туман войны рассеивается быстрее |
| Реликварный зал (IV) | Литургия Колосса — открывает титана · Освящённые реликвии — снаряжение III · Ковчег мощей — +1 реликвия каждые 120 с · **Печать Вознесения** — нужна для тира V |

**Правила**
- В одном здании — одно исследование за раз; очередь до 3. Разные ключевые здания исследуют параллельно.
- Разрушение ключевого здания отменяет текущее исследование (ресурсы возвращаются на 50%), изученное сохраняется.
- У каждой фракции свои ключевые здания и исследования — таблица в карточке FactionTiers.
