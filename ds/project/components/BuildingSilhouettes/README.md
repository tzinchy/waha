# BuildingSilhouettes

Схемы силуэтов зданий с размером на строительной сетке — техзадание для моделлера окружения.

**Язык форм**
- Каждое здание — ступенчатый зиккурат: уступы шагом в 1/8 высоты, центральная вертикаль (шпиль, труба, башня) выше всего остального.
- Окна — только узкие вертикальные щели и круглая розетка с лучами; всё, что светится, — `art-glow` (союзник) или `art-fire` (производство).
- Цоколь из `art-iron` по всему периметру: здание «стоит», а не лежит на земле.

**Роли и размер**
- Собор 4×4 — штаб, нанимает строителей. Самое высокое здание базы, шпиль виден из любой точки карты.
- Казарма 3×2 — пехота; знамёна `art-blood` с двух сторон ворот — место для командного цвета.
- Литейня 3×3 — генератор золота; горн `art-fire` и дым из труб показывают, что она работает.
- Ихорный насос 2×3 — генератор ихора; качающийся балансир и колба с уровнем `art-glow`.
- Лампа-маяк 1×1 — оборона и обзор; лучи света = радиус обзора.
- Реликварий 2×2 — нейтральная точка захвата; кристалл меняет цвет по владельцу.

**Правила**
- Командный цвет — только на знамёнах, кристаллах и свете ламп, не на основной латуни: база игрока узнаётся по силуэту, сторона — по свету.
- Здание под атакой — не перекрашивать модель; вместо этого `glow-blood` на рамке в интерфейсе и оповещение `lc-alert--danger`.
