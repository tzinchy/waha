# RangeIndicators

Радиусы на земле: дальность оружия, обзор, сектор обстрела турели, мёртвая зона артиллерии, радиус врага при наведении и ауры.

| Радиус | Вид | Когда виден |
| --- | --- | --- |
| Дальность оружия | сплошная линия `gilt-500`, заливка 8% | выбран юнит или турель; при отдаче приказа атаки |
| Обзор | точечная линия `ink-muted`, без заливки | выбран юнит; зажат Alt |
| Сектор турели | сектор `gilt-500` 14% | выбрана турель; при установке |
| Мёртвая зона | штриховка `blood-300` | артиллерия и батареи: ближе не стреляют |
| Радиус врага | пунктир `blood-300` 8 / 5 | наведение на вражеский юнит или турель |
| Аура / лечение | `verdigris-500` 10% | выбран целитель или знамя |

**Правила**
- В 3D радиус — декаль на рельефе, огибает холмы; на краю — тонкая светлая кромка, чтобы читаться на любой земле.
- Выбрано несколько юнитов — показывается объединённый контур дальностей, не десятки кругов.
- Alt — показать радиусы всех своих турелей; Alt + наведение на врага — его радиус.
- Свои и чужие радиусы различаются тремя способами: цвет, сплошная / пунктирная линия, заливка есть / почти нет.
- Цифры дальности — в карточке юнита (`lc-unit__stats`, «ДАЛ. 44») и в подсказке.
