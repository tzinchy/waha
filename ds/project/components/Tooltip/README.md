# Tooltip

Подсказка к команде, постройке или юниту: имя, горячая клавиша, цена, описание и невыполненные требования.

**Разметка:** `div.lc-tip[role=tooltip]` → `p.lc-tip__title` (`strong` + `kbd`), `p.lc-tip__cost` (span на каждую цену; нехватка — класс `lack`), `p.lc-tip__body` (бонусы в `em`), необязательный `p.lc-tip__req`.

**Правила**
- Заголовок — Cormorant SC 20px `gilt-300`; описание — `body-sm` в `ink-muted`; бонусы — `verdigris-300`; нехватка и требования — `blood-300`.
- Ширина до 300px, фаска `chamfer-md`, латунная кромка сверху. Тень `shadow-panel` при показе над картой.
- Появляется через 250 мс после наведения, исчезает сразу. Не перекрывает сетку команд — открывается над ней.
- Иконки цен — те же формы, что в `lc-res`.
