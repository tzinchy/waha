# CapturePoint

Точки захвата в мире и на HUD: пять состояний маркера и полоса победных очков.

**Три типа точек:** стратегическая (Знаменный столп) даёт влияние, +8 за 10 с; Реликварий даёт реликвии, +1 за 90 с; критическая точка (звезда) отнимает очки у противника, пока вы её держите. Все три используют одни и те же состояния маркера.

**Маркер `lc-cap`**: кольцо `lc-cap__ring` вокруг здания точки, ромб с буквой точки `lc-cap__letter`, название состояния и пояснение.

| Состояние | Кольцо | Знамя / кристалл | Подпись |
| --- | --- | --- | --- |
| `--neutral` | точки `ink-muted` | знамя кость `art-bone` | «Ничья» |
| `--capturing` | заполняется `verdigris-500` по часовой (`--cap: 0–100%`) | кость | «Захват · 3 юнита · 0:18» |
| `--ally` | сплошное `verdigris-500` | `art-glow` | «Наша» |
| `--enemy` | пунктир `blood-300` | `art-blood-lit` | «Вражеская» |
| `--contested` | мигает `amber-500` | прежний | «! Захват заморожен» |

**Полоса очков `lc-score`**: ромбы всех точек по порядку букв (заливка = владелец), полоса перетягивания (союзник сплошной `verdigris-500` слева, противник штриховкой `blood-300` справа, отметка середины `gilt-300`) и счёт до победы.

**Правила**
- Буквы точек — кириллица по порядку: А, Б, В, Г, Д. Одна и та же буква на маркере, на HUD и на мини-карте.
- В 3D кольцо — декаль на земле радиусом зоны захвата (по умолчанию 12 м); на экране всегда видна буква над шпилем.
- Владелец читается тремя способами: цвет, тип кольца (сплошное / пунктир / точки), свет кристалла.
