# CaptainAbilities

Дерево способностей капитана: три ветки (Вера, Война, Командование) по три тира, очки получаются за уровни в бою.

**Узел `lc-node`**: ромб с иконкой (`lc-node__gem`), счётчик рангов `lc-node__rank`, подпись.
- `--on` — изучено: латунная заливка, иконка `on-gilt`.
- `--open` — можно изучить сейчас: латунный контур и пульсирующее свечение `glow-gilt`.
- без модификатора — закрыто: контур `hairline`, подпись `ink-disabled`.
- `--ult` — абсолютная способность (крупнее), одна на дерево.

**Тиры дерева**: I — с уровня 1, II — с уровня 4 и ранга II, III — с уровня 7 и ранга III. Нужно и то и другое: высокий уровень без тех-тира не откроет III.

**Способности (пример Ордена)**
- Вера: Литания стойкости (аура +броня) → Свет лампы (лечение по площади) → Мученичество (при гибели — воскрешение отряда рядом).
- Война: Рывок → Сокрушение (оглушение) / Вихрь (урон вокруг) → **Падение шпиля** (абсолютная: удар с неба по площади 12 м, 1 раз за 3 мин).
- Командование: Знамя роты (мораль) → Перекличка (отряды восстанавливают 15% здоровья) → Последний рубеж (отряды рядом не умирают 6 с).

**Правила**
- Активные способности попадают на панель `lc-cmd` капитана в порядке изучения; абсолютная — всегда в последней ячейке, с латунной рамкой `stroke-heavy`.
- Перераспределение очков — только между боями.
