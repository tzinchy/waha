# CommandGrid

Сетка команд и способностей 4×3 в правом нижнем углу HUD; каждая ячейка — иконка, горячая клавиша и цена.

**Разметка:** `div.lc-cmd` (`role="toolbar"`) с 12 детьми `button.lc-cmd__cell` → `svg` 28px, `span.lc-cmd__key`, необязательный `span.lc-cmd__cost`. Пустые слоты — `span.lc-cmd__cell.lc-cmd__cell--empty`.

**Состояния**
- обычное — фон `surface-200`, иконка `gilt-500`, контур `gilt-700`.
- наведение — `surface-300`, иконка `gilt-300`, контур `gilt-500`; рядом открывается `lc-tip`.
- `lc-cmd__cell--active` + `aria-pressed="true"` — латунная заливка, иконка `on-gilt`: команда ждёт цели.
- `lc-cmd__cell--cooldown` — шторка `scrim` по часовой; доля задаётся `--cd: 0–100%`, секунды — `span.lc-cmd__timer` (`amber-300`).
- `lc-cmd__cell--locked` + `aria-disabled="true"` — иконка `opacity-disabled`, цена `blood-300`.

**Правила**
- Раскладка фиксирована: верхний ряд — движение/стоп/удержание/атака, ниже — постройки и способности. Не переставляйте базовые команды между юнитами.
- Горячая клавиша видна всегда (`readout`, 11px) — это часть обучения игрока.
- Размер ячейки 56px, зазор `space-1`; ячейки с фаской `chamfer-sm`.
