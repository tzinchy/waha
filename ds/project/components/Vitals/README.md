# Vitals

Полосы щита и здоровья с насечками каждые 10% — для карточки юнита, здания и полос над головой.

**Разметка:** `<div class="lc-vitals">` → `div.lc-vitals__bar` (заполнение через CSS-переменную `--v: 0–100%`), по желанию `div.lc-vitals__nums`.

**Полосы**
- `lc-vitals__bar--shield` — тонкая (6px), `steel-300`. Всегда сверху.
- `lc-vitals__bar` — здоровье, `verdigris-500` при > 50%.
- `lc-vitals__bar--worn` — `amber-500` при 25–50%.
- `lc-vitals__bar--critical` — `blood-300` при < 25%; на контейнер — `lc-vitals--critical`, тогда число становится `blood-300` с метой «▲».

**Правила**
- Порог меняет и цвет, и цифру с метой — состояние читается без цвета.
- Полосы над юнитами на карте: только `lc-vitals__bar`, без чисел, ширина = радиус выделения.
- Цвет полосы описывает здоровье, а не сторону. Принадлежность показывайте кольцом выделения под юнитом: союзник — `verdigris-500` сплошное, враг — `blood-300` пунктирное.
