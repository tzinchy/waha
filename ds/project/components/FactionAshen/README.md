# FactionAshen

Пресет фракции «Пепельный Синклит»: тема интерфейса `ashen`, палитра мира, базовый состав по тирам и особая механика.

**Как применить**
- Интерфейс: `data-theme="ashen"` на корне HUD (или на любом контейнере) — все `lc-*` компоненты перекрашиваются: металл рамок, поверхности, кольцо фокуса. Сигнальные цвета (`verdigris-*`, `blood-*`, `amber-*`) одинаковы у всех фракций — игрок не переучивается.
- Мир: класс `fac-ashen` на силуэте (`svg.lc-art`) — те же цветовые зоны берут палитру фракции (`ashen-main` … `ashen-cloth`).

**Особая механика.** **Порча.** Вокруг зданий Синклита земля обращается в пепел; на ней демоны восстанавливают 2% здоровья в секунду, а чужие строители не могут строить. Любой свой отряд можно принести в жертву на Алтаре — его Легион мгновенно превращается в демона того же веса.

**Модификаторы:** регенерация на Порче; жертвы → демоны; нет брони у пехоты; вне Порчи −10% урона.

**Состав (база):** Служка Пепла — строитель, тир I, Одержимый — пехота, тир I, Пепельный Канцлер — элита, тир II, Пожиратель Шпилей — титан, тир IV, Чёрный Алтарь — штаб, тир I.

**Язык форм**
- Рваные, асимметричные, с рогами и шипами, но с ар-деко ритмом: шипы растут ступенями, пламя — веером. Никаких восьмиконечных звёзд и чужих символов — знак Синклита это перевёрнутый ступенчатый шпиль. Сера на копоти, свет — адское пламя.
