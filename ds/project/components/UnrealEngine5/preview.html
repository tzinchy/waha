HUD и менюUMG + Common UICommon UI даёт навигацию с геймпада и фокус: стиль фокуса = focus-ring

Способности, тиры, уровни капитанаGameplay Ability SystemAbilities — способности, Gameplay Effects — снаряжение и тиры, Attributes — опыт и уровень
РесурсыAttribute Set игрока / Subsystemсобытие изменения → всплывающее число и .is-tick в панели
Массовая пехотаMass Entity + Animation to Textureтысячи пехотинцев на вершинных анимациях; скелет — только для капитанов и титанов
