# FactionTiers

Ключевые здания тиров I–IV, здание призыва тира V и три легенды для каждой фракции; строка окрашена темой своей фракции.

| Фракция | Ключевые здания I → IV | Тир V | Легенды |
| --- | --- | --- | --- |
| Орден Вечной Лампы | Скрипторий · Храм-кузня · Обсерватория Лампы · Реликварный зал | Врата Вечной Лампы | Святая Ирена — лечащая аура; Последний Магистр — рывок по линии; Латунный Серафим — пикирование с неба |
| Безмолвный Двор | Костница-Архив · Плавильня Праха · Колокольня Скорби · Мавзолей Королей | Чёрный Неф | Королева-Вдова — поднимает всех павших в 20 м; Безглавый Маршал — бессмертен, пока рядом есть останки; Хор Тысячи — крик страха по площади |
| Призменный Консенсус | Линзовая мастерская · Ангар каркасов · Узел наведения · Зеркальная палата | Великая Линза | Первый Голос — вся армия видит то, что видит он; Близнецы-Каркасы — два каркаса с общим здоровьем; Рой «Тысяча глаз» — снимает туман войны на 30 с |

**Правила для всех фракций**
- Структура одинакова: 4 ключевых здания (по одному на тир I–IV), в каждом — 4 исследования, последнее исследование тира IV открывает переход на V.
- Здание призыва — самое высокое здание фракции; его силуэт должен быть виден с любой точки карты.
- Легенды — по одной на поле; у каждой одна сигнатурная способность, которая меняет бой, а не просто наносит больше урона.
