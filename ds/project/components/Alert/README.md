# Alert

Строка оповещения в левой части HUD: знак, короткий текст события и метаданные (квадрат, время, нехватка).

**Разметка:** `div.lc-alert` → `span.lc-alert__glyph` (svg 22px), `span.lc-alert__text`, необязательный `span.lc-alert__meta`. Тревогам — `role="alert"`, остальным — `role="status"`.

**Тона**
- `lc-alert--danger` — `blood-300`, треугольник: атака, гибель героя, потеря здания. Клик переводит камеру к событию.
- `lc-alert--warn` — `amber-300`, песочные часы: нехватка ресурса, лимит, перезарядка.
- `lc-alert--ok` — `verdigris-300`, ромб с галочкой: исследование, постройка, найдена реликвия.
- без модификатора — `gilt-300`: нейтральное событие.

**Правила**
- Текст — `label`, прописные, 2–4 слова; подробности — в `__meta` шрифтом `readout`.
- У каждого тона свой знак — смысл читается без цвета.
- Одновременно не больше четырёх строк; новая появляется сверху за 180 мс, через 5 с гаснет (тревога — через 8 с).
