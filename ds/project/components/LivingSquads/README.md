# LivingSquads

Отряды в покое не стоят как статуи: каждый боец дышит, переминается и поправляет оружие в собственном ритме.

**Слои движения в покое**
1. **Дыхание** — корпус чуть приподнимается от ступней (1–2 см), цикл 3.0–4.4 с.
2. **Переминание** — вес с ноги на ногу, сдвиг корпуса ±0.5 см, наклон ±0.6°.
3. **Поправка оружия** — раз в 2 цикла оружие поднимается и опускается на 3–4°.
4. **Ткань** — плащи и плюмажи колышутся с задержкой.
5. **Свет** — визоры и лампы медленно «дышат» яркостью.

**Правила**
- Длительность и фаза у каждого бойца случайные (`--idle-t` 3.0–4.4 с, `--idle-d` сдвиг до 3 с) — отряд никогда не двигается синхронно.
- Строй отряда — свободный, с шагом 1.4 м и смещением рядов; никаких идеальных шеренг.
- Каждые 8–15 с один случайный боец делает «особое» движение: осматривается, проверяет оружие, опирается на древко.
- Все силуэты в системе по умолчанию живут в покое (класс `lc-anim-idle` ставится автоматически); при «Уменьшить движение» — замирают.
