Схемы силуэтов зданий для концепт-досок и ТЗ моделлерам окружения — не игровая графика. Палитра `art-*` зашита в файл, фон прозрачный, земля — нижний край. Кристалл реликвария в файле нейтральный (`art-bone`); в игре он окрашивается по владельцу точки. Знаменный столп — banner. Ключевые здания тиров: scriptorium (I), forge (II), observatory (III), reliqhall (IV); здание призыва тира V — gate.
