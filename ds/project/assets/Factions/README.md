Схемы силуэтов фракций для концепт-досок и ТЗ моделлерам — не игровая графика. В каждый файл зашита палитра своей фракции (`undead-*`, `prism-*`, `clockwork-*`, `orks-*`, `ashen-*`), фон прозрачный, земля — нижний край. Нежить: digger, boneknight, wailer, ossuary, undead-hq. Призменный Консенсус: tender, lensman, strider, prismark, prism-hq. Часовые Династии: warden, legionary, chronarch, pendulum, clockwork-hq. Ржавая Орда: tinker, choppa, warboss, idol, orks-hq. Часовые Династии, вознесённый капитан: deity. Пепельный Синклит: servant, possessed, ashen-chancellor, devourer, ashen-hq, ashen-rift (тир V). Новые модели — Часовые Династии, бессмертная механика гробниц: eternal (Вечный воин), reaper (Пожинатель), scarabs (Скарабеи-ткачи), pharaoh (Фараон Династии), obelisk (Обелиск Вечности), tomb (Гробница Династии); прежние warden, legionary, chronarch, pendulum, clockwork-hq остаются как старые модели в палитре расплава. Пепельный Синклит, демоны: imp (Бес), renegade (Отступник), hound (Пёс Порчи), forge-demon (Кузнечный демон), demon-prince (Демон-князь), lord-of-ash (Владыка Пепла, тир V), rift (Разлом).
