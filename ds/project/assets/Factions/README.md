Схемы силуэтов фракций для концепт-досок и ТЗ моделлерам — не игровая графика. В каждый файл зашита палитра своей фракции (`undead-*`, `prism-*`, `clockwork-*`, `orks-*`, `ashen-*`), фон прозрачный, земля — нижний край. Нежить: digger, boneknight, wailer, ossuary, undead-hq. Призменный Консенсус: tender, lensman, strider, prismark, prism-hq. Часовые Династии: warden, legionary, chronarch, pendulum, clockwork-hq. Ржавая Орда: tinker, choppa, warboss, idol, orks-hq. Часовые Династии, вознесённый капитан: deity. Пепельный Синклит: servant, possessed, ashen-chancellor, devourer, ashen-hq, ashen-rift (тир V).
