Схемы оборонительных построек и уровней стратегической точки — ТЗ моделлерам, не игровая графика. Палитра `art-*` (у турелей Орды — `orks-*`, у купола — `prism-*`) зашита в файл, фон прозрачный, земля — нижний край. Орден: wall, gate, turret, battery, bunker, mine. Точка влияния: point-1, point-2, point-3. Особые: shieldgen (Консенсус), scrapgun и rocketbarrel (Орда).
