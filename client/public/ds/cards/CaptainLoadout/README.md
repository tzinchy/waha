# CaptainLoadout

Оружейная капитана: шесть слотов снаряжения вокруг фигуры, три тира предметов и список вариантов для выбранного слота.

**Слоты:** Шлем · Доспех · Спина (плащ / знамя / крылья-шпили) · Оружие · Вторая рука (щит / огнемёт-кадило / пусто) · Реликвия. Каждый слот меняет модель капитана — части модульные (см. CaptainArchetypes).

**Тиры снаряжения** (метка `lc-tier` + цвет рамки `lc-slotcard`)
- **I · Рядовое** — контур `ink-muted`, бесплатно, доступно с начала.
- **II · Освящённое** — контур `gilt-500`; покупается в бою за влияние и энергию с тех-тира II.
- **III · Реликвийное** — контур `amber-500`, имя `amber-300`; тех-тир III, лучшее — за реликвии на тир IV.

**Ранг капитана** растёт вместе с тех-тиром: I Сержант-капитан → II Командор → III Лорд-капитан. Ранг открывает тир снаряжения и ветки способностей; уровень (1–10) копится в бою — см. CaptainLevelUp.

**Список предметов `lc-itemrow`**: тир, имя, ключевые характеристики (`readout`), цена с `lc-ico`, состояние: «Надет» (`--on`), «Доступен», «В запасе», требование (`--locked`, `blood-300`).

**Правила**
- Смена снаряжения в бою — только у Оружейной или штаба, 3 с без возможности атаковать.
- Фигура в центре — живая (`lc-anim-idle`), за ней вращается ар-деко «солнце» `lc-burst`.
