# UnrealEngine5

Карта переноса дизайн-системы в Unreal Engine 5: что чем становится и какие файлы готовы к импорту.

**Готовые файлы** (папка `exports/ue5/` этой системы)
- `DT_UI_Order.csv`, `DT_UI_Pergament.csv`, `DT_UI_Undead.csv`, `DT_UI_Prism.csv`, `DT_UI_Clockwork.csv`, `DT_UI_Orks.csv`, `DT_UI_Ashen.csv` — цвета интерфейса для каждой темы.
- `DT_ArtPalette.csv` — палитра мира и палитры фракций.
- `DT_Surfaces.csv` — параметры поверхностей моделей (металл, шероховатость, свечение) — не ресурсы.

**Импорт.** Создайте структуру строки `FLcColorRow` с полями `Color` (Linear Color), `Hex` (String), `Usage` (String) и `FLcSurfaceRow` с полями `BaseColor` (Linear Color), `Metallic`, `Roughness`, `Emissive` (Float), `Usage` (String). Перетащите CSV в Content Browser и выберите эту структуру. Цвета в CSV уже переведены из sRGB в линейное пространство — не переводите второй раз.

**Смена темы фракции** — один Data Table на тему; виджеты берут цвет по имени токена (`gilt-500`, `surface-200`…), поэтому смена фракции = смена таблицы.

**Рекомендации**
- Lumen красив в заставках, но в бою с десятками ламп и горнов проверяйте производительность заранее; запасной вариант — запечённый свет для статики и точечные источники без теней для ламп.
- Капитаны и титаны — полноценные скелеты и Anim Montages; массовая пехота — Mass Entity с вершинными анимациями.
- Всё, что в системе описано как «стоп-кадр», «тряска», «вспышка», настраивается через Notifies в монтажах и Camera Shake — держите значения из MotionTiming.
