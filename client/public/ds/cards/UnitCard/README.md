# UnitCard

Карточка выбранного юнита или здания в нижней панели HUD: портрет, имя, класс, полосы жизни и характеристики.

**Разметка:** обычно внутри `lc-frame`. `div.lc-unit` → `div.lc-unit__portrait` (портрет — изображение или SVG 56×72, `span.lc-unit__rank` — римская цифра ранга) и колонка с `h3.lc-unit__name`, `p.lc-unit__class`, `lc-vitals`, `p.lc-unit__stats` (пары `ПОДПИСЬ <b>значение</b>`).

**Правила**
- Имя — `title-2` цветом `gilt-300`, класс — `label-sm` прописными в `ink-muted`.
- Характеристики — `readout`; подписи `ink-muted`, значения `ink`. Бонус от улучшения — значение `verdigris-300`, штраф — `blood-300` со стрелкой ▲/▼.
- Портрет — в двойной рамке: `stroke-heavy` `gilt-500` + внешний контур `gilt-700`. Для врага — та же рамка в `blood-300`.
- При выделении группы карточка сменяется сеткой малых портретов 48×56 с одной полосой здоровья у каждого.
- Портрет в превью — заглушка; художественные портреты рисует художник игры.
