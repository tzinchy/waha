# MapExample

Пример карты 1×1 «Разлом Святого Шпиля»: зеркальная по центру, с тремя типами точек, жилами, укрытиями и высотами.

**Состав (на сторону):** база в углу, 3 стратегические точки (А–В / Г–Е), 1 реликварий, 2 жилы под Глубинные насосы, 3 тяжёлых и 3 лёгких укрытия. Общие: 3 критические точки (I, II, III), река с двумя мостами, два плато с руинами.

**Правила построения карт**
- Симметрия поворотом на 180° вокруг центра — честная для обеих сторон. Центральная критическая точка II — у моста, через неё идёт главный путь.
- Ближайшая к базе стратегическая точка — в 25–30 с ходьбы пехоты; реликварий — на высоте, его видно издалека, но к нему ведёт один подъём.
- Жилы стоят рядом с базой (безопасная) и у центра (рискованная, богаче).
- Укрытия: тяжёлое (руины, стены — штриховка `gilt-500`) снижает урон по пехоте на 50%; лёгкое (воронки, кусты — точки `ink-muted`) на 25%. Узкие проходы — между скалами (`surface-300` с контуром `gilt-700`).
- Обозначения на тактической карте совпадают с мини-картой и маркерами в мире: ромб = влияние, арка = реликвии, звезда = победа.
- Масштаб: 80 px = 100 м; карта 1×1 — около 600 × 360 м.
