# Generator

Панель здания-генератора ресурса: живая анимация работы, всплывающий доход, выработка, слоты рабочих, состояние жилы и улучшение.

**Разметка:** `lc-frame` → `lc-frame__head` → `div.lc-gen` → `div.lc-gen__art` (силуэт с `lc-anim-work` + `span.lc-float` с суммой) и колонка: `p.lc-gen__rate`, `div.lc-slots` (`span.lc-slot` с силуэтом или `lc-slot--empty`), строки `div.lc-gen__row`, кнопка улучшения.

**Генераторы**
- **Литейня** — золото. Работает: горит горн `art-fire`, идёт дым `art-ash`. Остановлена: горн гаснет, дыма нет.
- **Ихорный насос** — ихор. Работает: качается балансир, колба пульсирует `art-glow`. Жила истощается — строка `amber-300` с «▼», при 0% — оповещение `lc-alert--warn`.

**Правила**
- Всплывающий доход над зданием в мире: `+12` `verdigris-300`, поднимается на 28 px за 2 с; при отдалении камеры дальше 50 м не показывается.
- Слоты рабочих: каждый занятый слот = +33% эффективности; пустой слот — «+», клик отправляет ближайшего свободного строителя.
- Выработка всегда «за 10 с», чтобы игрок сравнивал генераторы без пересчёта.
