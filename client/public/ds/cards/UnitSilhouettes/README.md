# UnitSilhouettes

Схемы силуэтов и цветовых зон юнитов — техзадание для 3D-моделлера, а не готовая графика.

Плоские фигуры показывают три вещи, которые модель обязана сохранить: **силуэт** (узнаётся с камеры RTS), **крупные цветовые зоны** (латунь, железо, свечение) и **одну опознавательную деталь** у каждого юнита. Детализация, объём, износ и освещение — работа художника; финальный вид определяется рендером движка.

**Опознавательные детали**
- Латунный Стражник — стрельчатый шлем с горящей щелью-визором, алебарда выше головы.
- Каменщик — фонарь на шесте за спиной (виден в тумане войны), молот.
- Кадильщица — ступенчатая митра, кадило на цепи с дымом.
- Канонир Литейни — орудие с рёбрами-кольцами через плечо.
- Шпиль-ходок — шагоход-собор: шпиль и окно-розетка на двух ногах.
- Пепельный Канцлер (демоны, Пепельный Синклит) — корона-шипы, рваная мантия, посох-крюк; в палитре фракции — `ashen-*`.

**Правила**
- Союзные юниты: латунь `art-brass` ≥ 50% площади силуэта, свечение `art-glow`. Противник: латуни нет вовсе — `art-blood`, `art-blood-lit`, глаза `art-fire`.
- Кольцо выделения: союзник — сплошное `verdigris-500`, противник — пунктир `blood-300`, нейтральный — точки `ink-muted`.
- Каждый юнит выше человека (1.8 м) кроме строителя — строитель должен казаться уязвимым.
- Плоские версии лежат в ассетах (группа Units) для концепт-досок.
