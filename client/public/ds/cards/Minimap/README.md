# Minimap

Мини-карта в левом нижнем углу HUD: рельеф, туман войны, юниты, базы, точки захвата, рамка камеры и сигнал тревоги.

**Разметка:** `div.lc-minimap` (двойная латунная рамка) с `svg` 224 × 224; классы фигур: `ground`, `cliff`, `river`, `fog`, `ally`, `enemy`, `base-ally`, `base-enemy`, `pt`, `pt-ally`, `pt-enemy`, `cam`, `ping` (+ `lc-ping` для анимации).

**Правила**
- Сторона читается формой: союзники — квадраты `verdigris-500`, противник — треугольники `blood-300`, базы — крупные фигуры, точки захвата — ромбы с той же заливкой, что на HUD.
- Оспариваемая точка — ромб с обводкой `amber-500`; туман — вуаль `scrim` поверх рельефа.
- Рамка камеры — трапеция `ink` (камера наклонена, поэтому ближний край шире дальнего).
- Сигнал тревоги — кольцо `blood-300`, расходится за 1.2 с, повторяется 3 раза; клик по карте переносит камеру.
- Кнопки под картой — `lc-btn--sm lc-btn--ghost`: «Сигнал» (Alt+клик), «Рельеф».
