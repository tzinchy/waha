# Frame

Двойная латунная рамка со ступенчатыми скобами в углах — контейнер для любой панели HUD и меню.

**Разметка:** `<section class="lc-frame">…</section>`. Потребитель задаёт ширину и содержимое.

**Части**
- `lc-frame__head` + внутренний `<span>` — заголовок между линиями с ромбами: «— ◆ БРИФИНГ ◆ —». Текст `gilt-300`, стиль `label`.
- `lc-frame__plate` — латунная плашка на верхней кромке (заливка `gilt-500`, текст `on-gilt`). Для имени окна или цели миссии. Одна на рамку; дайте рамке отступ сверху ≥ 12px.

**Модификаторы**
- `lc-frame--lg` — отступ `space-6`, длинные скобы. Модальные окна, брифинг.
- `lc-frame--alert` — скобы `blood-300`, свечение `glow-blood`. Окно поражения, атакованное здание.

**Правила**
- Фон тела — `surface-200`, внешний контур `gilt-700`, внутренняя линия `gilt-500` на `space-1` внутрь.
- Не вкладывайте рамку в рамку: внутри используйте разделители `hairline`.
- Скобы рисуются фоном — не задавайте рамке `background` целиком, только `background-color`.
