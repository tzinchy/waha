# FactionClockwork

Пресет фракции «Часовые Династии»: тема интерфейса `clockwork`, палитра мира, базовый состав по тирам и особая механика.

**Как применить**
- Интерфейс: `data-theme="clockwork"` на корне HUD (или на любом контейнере) — все `lc-*` компоненты перекрашиваются: металл рамок, поверхности, кольцо фокуса. Сигнальные цвета (`verdigris-*`, `blood-*`, `amber-*`) одинаковы у всех фракций — игрок не переучивается.
- Мир: класс `fac-clockwork` на силуэте (`svg.lc-art`) — те же цветовые зоны берут палитру фракции (`clockwork-main` … `clockwork-cloth`).

**Особая механика.** **Перезавод.** Уничтоженная пехота заводится заново через 12 с на месте гибели, если рядом Хронарх или Хранилище. Влияния нет: всё стоит энергию, а захваченные точки ускоряют перезавод на 30%.

**Модификаторы:** пехота возвращается; только энергия; стройка медленнее на 25%.

**Состав (база):** Смотритель — строитель, тир I, Заводной легионер — пехота, тир I, Хронарх — элита, тир II, Маятник — титан, тир IV, Хранилище Сна — штаб, тир I.

**Язык форм**
- Безликие овальные маски с одной вертикальной щелью, видимые шестерни в груди, нимбы-циферблаты, копья-стрелки. Обсидиан и сталь, свет — расплав. Никаких скелетов.
