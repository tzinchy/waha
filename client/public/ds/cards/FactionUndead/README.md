# FactionUndead

Пресет фракции «Безмолвный Двор»: тема интерфейса `undead`, палитра мира, базовый состав по тирам и особая механика.

**Как применить**
- Интерфейс: `data-theme="undead"` на корне HUD (или на любом контейнере) — все `lc-*` компоненты перекрашиваются: металл рамок, поверхности, кольцо фокуса. Сигнальные цвета (`verdigris-*`, `blood-*`, `amber-*`) одинаковы у всех фракций — игрок не переучивается.
- Мир: класс `fac-undead` на силуэте (`svg.lc-art`) — те же цветовые зоны берут палитру фракции (`undead-main` … `undead-cloth`).

**Особая механика.** **Жатва.** Каждый павший — свой или чужой — оставляет останки. Могильщики поднимают из них Костяных латников без затрат влияния. Генераторов нет: энергию даёт Скорбь, +1 за каждую смерть рядом со Склепом.

**Модификаторы:** бесплатная пехота из павших; нет генераторов энергии; лечение только у склепов.

**Состав (база):** Могильщик — строитель, тир I, Костяной латник — пехота, тир I, Плакальщица — элита, тир II, Ковчег-Костница — титан, тир IV, Склеп-Престол — штаб, тир I.

**Язык форм**
- Высокие и тонкие, рваные края саванов, рёбра наружу, шлемы-черепа без нижней челюсти. Свет — холодный призрачный, не зелёный. Никакой латуни — тусклое серебро и кость.
