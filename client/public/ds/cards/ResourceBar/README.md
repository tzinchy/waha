# ResourceBar

Верхняя полоса ресурсов: иконка-форма, число и подпись для каждого ресурса и лимита войск.

**Разметка:** `<div class="lc-res">` с детьми `<div class="lc-res__item">` → `svg.lc-res__icon`, `span.lc-res__value` (доход — во вложенном `<small>`), `span.lc-res__label`.

**Состояния**
- обычное — число `gilt-300`, доход `verdigris-300`, иконка `gilt-500`.
- `lc-res__item--warn` — янтарь (`amber-300`/`amber-500`): лимит ≥ 90% или ресурс иссякает.
- `lc-res__item--cap` — кровь (`blood-300`) + слово «ПРЕДЕЛ» в подписи: лимит достигнут, строить нельзя.

**Правила**
- Числа — `numeric`, `tabular-nums`, разделитель — неразрывный пробел: `1 240`.
- Каждому ресурсу — своя форма иконки (Влияние — ромб, Энергия — молния, Реликвии — арка, Легион — щит); не различайте ресурсы только цветом.
- Полоса прижата к верхнему краю экрана, ширина — по содержимому; нижняя латунная кромка `stroke-frame` отделяет её от карты.
- Обновление значения: число мигает `gilt-300 → ink` за 200 мс, без прыжков.
