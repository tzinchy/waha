# AttackVFX

Разнообразие атак и боевых эффектов: у каждого типа оружия — своя поза, свой след и своё попадание.

| Атака | Поза | След / эффект | Тайминг |
| --- | --- | --- | --- |
| Когти Вожака | лапа заносится за голову, корпус скручивается | три светлых дуги-следа, искры, стоп-кадр | 1.4 с: замах 0–36%, удар 40%, стоп-кадр 40–48% |
| Рубящий удар | тесак сверху вниз | одна вертикальная дуга, кольцо пыли | 1.3 с |
| Укол алебардой | выпад вперёд | две горизонтальные полосы, искры на острие | 1.2 с |
| Луч линзы | стрелок неподвижен | луч мерцает, кольцо попадания | 2 с, луч 1 с |
| Огненный шар | посох вверх, набор | шар летит по дуге, хвост пламени | 2 с |
| Зажигательная граната | бросок навесом | вспышка, кольцо, пламя на земле 4 с | 3 с |
| Дымовое кадило | бросок навесом | клубы растут и сливаются, держатся 12 с | 4 с |
| Литургический заряд | ставится вплотную | белая вспышка, ударная волна, обломки | 2 с |

**Правила**
- У каждого оружия — **своя форма следа**: когти — три тонких параллельных дуги, тесак — одна широкая, копьё — прямые полосы, огонь — языки, дым — круглые клубы. Игрок узнаёт атаку по форме, а не по цвету.
- Цвета эффектов — из палитры мира: огонь `art-fire`, свет `art-glow`, дым `art-ash`, у фракций — их `-glow` (луч Консенсуса — `prism-glow`, пламя Синклита — `ashen-glow`).
- Сила удара показывается стоп-кадром и размером вспышки, а не длительностью: тяжёлые удары — стоп-кадр 90 мс, лёгкие — 40 мс.
- В UE5: следы ударов — Niagara Ribbon по сокету оружия, вспышки и волны — Niagara Sprite, горение земли — декаль с эмиссией.
