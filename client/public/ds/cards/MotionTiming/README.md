# MotionTiming

Референс поз, тайминга и «сочности» анимаций: замах, удар, стоп-кадр, вспышка, частицы, инерция ткани.

**Пять правил сочности**
1. **Замах дольше удара.** Подготовка 30–35% цикла, сам удар — 5–6%. Медленно-медленно-РЕЗКО.
2. **Стоп-кадр (hit-stop) 60–90 мс** в момент попадания: атакующий и цель замирают, модель вспыхивает (`brightness 1.7`), вылетают искры `art-fire`.
3. **Вторичное движение** — плащ, плюмаж, цепь, кадило догоняют тело с задержкой 6–10% цикла и перелетают дальше.
4. **Вес по массе:** пехота — подскок 3 см, шагоход — проседание + тряска камеры 2–4 см, титан — пыль кольцом и звук на каждом шаге.
5. **Смерть — это событие:** вспышка, отброс назад, падение, отскок, пауза, рассыпание пеплом `art-ash`. Не просто исчезновение.

| Состояние | Цикл | Ключевые доли |
| --- | --- | --- |
| Покой | 3.2 с | дыхание от ступней, свет визора 2.4 с |
| Ходьба пехоты | 0.9 с | касание 0% и 50% + облачко пыли |
| Удар | 1.3 с | замах 0–34%, рывок 34–40%, стоп-кадр 40–47%, отдача, дотяжка |
| Выстрел | 1.6 с | отдача 0–6%, дым из ствола 4–60% |
| Колдовство | 2 с | набор 0–55%, волна 55–62% |
| Гибель | 3.2 с | вспышка 1–4%, отброс 4–10%, падение до 30%, отскок 34%, пепел 52–100% |
| Шаг шагохода | 1.4 с | пауза на касании 50–55%, тряска 50–58% |
| Парение | 2.8 с | ±4 см, луч 1.4 с |

**Кривые:** `--ease-snap` cubic-bezier(.7,0,.84,0) — рывок; `--ease-settle` cubic-bezier(.16,1,.3,1) — дотяжка и всплывающие числа; `--ease-heavy` cubic-bezier(.65,0,.35,1) — массивное.

**Интерфейс тоже живой:** блик по латунной кнопке при наведении 0.9 с, оповещение въезжает слева 0.42 с, тревога трижды вспыхивает, число ресурса подпрыгивает при изменении (`.is-tick`), всплывающий доход с перелётом, окно нового уровня — «солнце» вращается за 18 с.

**Доступность.** Всё выключается при `prefers-reduced-motion`; в игре — «Уменьшить движение»: без тряски камеры, без вспышек ярче 1.3, стоп-кадр сохраняется.

Классы для прототипов: `lc-anim-idle`, `-walk`, `-attack`, `-recoil`, `-cast`, `-death`, `-ritual`, `-stride`, `-hover`, `-work`, `-build`.
