# FactionPrism

Пресет фракции «Призменный Консенсус»: тема интерфейса `prism`, палитра мира, базовый состав по тирам и особая механика.

**Как применить**
- Интерфейс: `data-theme="prism"` на корне HUD (или на любом контейнере) — все `lc-*` компоненты перекрашиваются: металл рамок, поверхности, кольцо фокуса. Сигнальные цвета (`verdigris-*`, `blood-*`, `amber-*`) одинаковы у всех фракций — игрок не переучивается.
- Мир: класс `fac-prism` на силуэте (`svg.lc-art`) — те же цветовые зоны берут палитру фракции (`prism-main` … `prism-cloth`).

**Особая механика.** **Сеть наведения.** Дроны и стрелки помечают цели: по помеченному врагу все отряды Консенсуса бьют на 25% точнее и на 4 м дальше. Ближнего боя почти нет — при контакте отряды отскакивают.

**Модификаторы:** дальность стрельбы +15%; прыжковые каркасы; ближний бой −40%.

**Состав (база):** Наладчик — строитель-дрон, тир I, Линзовый стрелок — пехота, тир I, Каркас-скороход — элита, тир II, Призма-ковчег — титан, тир IV, Узел Консенсуса — штаб, тир I.

**Язык форм**
- Обтекаемый ар-деко 1930-х: капли, яйца, горизонтальные полосы-визоры, линзы. Фарфор и графит, свет — тёплый луч линзы. Ни одного острого шипа.
