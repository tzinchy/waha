# BuildMenu

Меню строителя: кто выбран, вкладки категорий, карточки зданий с ценой, временем и горячей клавишей.

**Разметка:** внутри `lc-frame`. `div.lc-buildhead` (силуэт строителя, число выбранных, скорость стройки) → `div.lc-tabs[role=tablist]` с `button[role=tab]` → `div.lc-build` с карточками `button.lc-bcard` → `p.lc-buildhint`.

**Карточка `lc-bcard`**: силуэт здания 56 px, `span.lc-bcard__name`, `span.lc-bcard__cost` (по `span` на цену; нехватка — класс `lack`), `kbd` с клавишей.
- выбрана — `aria-pressed="true"`: рамка `stroke-heavy` `gilt-500`, курсор переходит в режим установки (`Placement`).
- не хватает ресурса — карточка активна, недостающая цена `blood-300` и пустым значком ◇.
- заблокирована — `lc-bcard--locked` + `aria-disabled="true"`: силуэт серый с `opacity-disabled`, вместо цены — требование.

**Правила**
- Порядок вкладок постоянный: Экономика → Армия → Оборона → Святыни. Горячие клавиши — первая буква здания, они не меняются между вкладками.
- Несколько строителей ускоряют стройку: показывайте множитель в шапке, а не в карточке.
- Меню занимает место сетки команд `lc-cmd` в правом нижнем углу; Esc и ПКМ возвращают сетку команд.
