# FactionOrder

Пресет фракции «Орден Вечной Лампы»: тема интерфейса `dark`, палитра мира, базовый состав по тирам и особая механика.

**Как применить**
- Интерфейс: `data-theme="dark"` на корне HUD (или на любом контейнере) — все `lc-*` компоненты перекрашиваются: металл рамок, поверхности, кольцо фокуса. Сигнальные цвета (`verdigris-*`, `blood-*`, `amber-*`) одинаковы у всех фракций — игрок не переучивается.
- Мир: класс `fac-dark` на силуэте (`svg.lc-art`) — те же цветовые зоны берут палитру фракции (`art-brass` … `art-blood`).

**Особая механика.** **Свет веры.** Отряды в радиусе маяков и знамён получают +2 брони и не обращаются в бегство. Капитан поднимает знамя роты — радиус света ×2 на 20 с.

**Модификаторы:** пехота прочнее на 15%; лучшие здания-укрепления; скорость отрядов −10%.

**Состав (база):** Каменщик — строитель, тир I, Стражник — пехота, тир I, Кадильщица — поддержка, тир II, Колосс — титан, тир IV, Собор — штаб, тир I.

**Язык форм**
- Ступенчатые шпили, стрельчатые шлемы, окна-розетки. Латунь ≥ 50% силуэта, свет ламп бирюзовый.
