# Construction

Здание в процессе стройки: призрак полной модели, построенная часть растёт снизу вверх, леса, полоса прогресса и строители.

**Разметка:** `div.lc-site` → `div.lc-site__stage` (силуэт-призрак `lc-site__ghost` + построенная часть `lc-site__built` с переменной `--rest: 100% − прогресс` + леса `svg.lc-site__scaffold`) → `lc-vitals` с `--v: прогресс` → подпись этапа и строителей.

**Этапы** (у каждого своя подпись и звук)
- **Закладка** 0–30% — цоколь `art-iron`, разметка клеток, первые опоры лесов.
- **Каркас** 30–80% — стены растут, леса поднимаются вместе с краем.
- **Освящение** 80–100% — леса снимаются, загораются окна `art-glow`; в 100% — короткая вспышка и оповещение «Собор возведён» (`lc-alert--ok`).

**Правила**
- В 3D: модель режется плоскостью снизу вверх (dissolve по высоте), над срезом — тонкая светящаяся кромка `art-brass-lit`; призрак полной модели — 16% непрозрачности.
- Полоса прогресса стройки — латунная (`gilt-500`), чтобы не путать со здоровьем. Здоровье строящегося здания растёт вместе с прогрессом и показывается отдельной полосой при наведении.
- Без строителей рядом стройка замирает: подпись «ПРИОСТАНОВЛЕНО» `amber-300`, леса без анимации.
